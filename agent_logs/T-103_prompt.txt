- `feather_filename(pair, timeframe, *, trading_mode="futures")`:
  "BTC/USDT:USDT" -> "BTC_USDT_USDT-5m-futures.feather" (futures; replace "/" and ":" with "_");

  Return a Path.
- `audit_data(data_dir, pairs, timeframes, *, timerange=None, exchange="binance",
  trading_mode="futures")` -> DataAudit:
  - reads each (pair, timeframe) feather via pyarrow (column `date` holds the candle open time,
    timestamp ms or ns, optionally tz-aware — normalize to UTC ms internally);
  - `duplicates` = count of repeated timestamps (diff == 0 after sort);
  - `gaps` = count of consecutive diffs > 1.5 * expected interval; `max_gap_minutes` =
    largest diff in minutes (0.0 if < 2 rows);
  - `ohlc_violations` = rows where high < max(open, close) OR low > min(open, close) OR
    high < low;
  - `zero_volume_rows` = rows where volume == 0;
  - missing file -> PairAudit(missing=True, path="", rows=0, ...) + an issue string;
  - `timerange` ("YYYYMMDD-YYYYMMDD", either side may be empty) -> expected row count from
    first/last candle stamps; missing_frac > 0.05 -> issue;
  - `ok` = False if any missing file, duplicates > 0, ohlc_violations > 0, or timerange
    coverage issue; `issues` tuple lists human-readable strings; `first_ts`/`last_ts` are
    UTC ISO strings ("" when missing).
- `download_args(config_container_path, pairs, timeframes, timerange, *, exchange="binance")`
  -> EXACT list: ["download-data", "--config", cfg, "--exchange", exchange, "--pairs", *pairs,
  "--timeframes", *timeframes, "--timerange", timerange]. (Trading mode comes from the config
  file — do NOT add a --trading-mode flag.)
- `data_checksums(data_dir, pairs, timeframes, *, exchange="binance", trading_mode="futures")`
  -> {relative posix filename: sha256 hex}; stream files in chunks; skip missing.
