## REQUIREMENTS
### runner.py (spec = INTERFACES.md §1, all details binding)
- `DEFAULT_IMAGE = "freqtradeorg/freqtrade:stable"`, `CONTAINER_USERDATA = "/freqtrade/user_data"`.
- `RunnerError(RuntimeError)`.
- `RunResult` frozen dataclass: argv (tuple), exit_code, stdout (combined out+err, utf-8
  errors="replace", ANSI escapes stripped), duration_s, log_path (Path|None).
- `Runner` typing.Protocol with `run()` and `map_path()`.
- `DockerRunner(user_data_dir, *, image=DEFAULT_IMAGE, docker_bin="docker")`:
  - `map_path(host_path)`: path under `user_data_dir` -> `/freqtrade/user_data/<rel>` posix
    (forward slashes); ValueError if outside or not under root.
  - `build_command(args)`: exactly `[docker_bin, "run", "--rm", "-v",
    f"{posix(user_data_dir)}:{CONTAINER_USERDATA}", image, *args]`.
  - `run(args, *, timeout_s=3600, log_dir=None, log_name=None)`: subprocess.run(cmd,
    capture_output=True, timeout=timeout_s); timeout -> exit_code 124 and stdout prefixed
    `TIMEOUT after <n>s\n` + partial output; missing docker binary -> RunnerError; when
    log_dir+log_name given also write the full combined output to log_dir/log_name and set
    log_path.
  - UTF-8 console safety on Windows: never crash on undecodable bytes.
### results.py (spec = INTERFACES.md §2)
- `StrategyStats` frozen dataclass (summary raw dict; trades/per_pair/pairlist tuples).
  Missing optional keys must be tolerated: `trades`/`results_per_pair`/`pairlist` absent ->
  empty tuple; `per_pair` EXCLUDES the row whose key == "TOTAL".
- `load_backtest_json(path)` — .zip (read the single non-config *.json entry, prefer
  `backtest-result-*.json`) or plain .json; ValueError on unreadable/malformed.
- `parse_backtest_result(path)` -> `{name: StrategyStats}`; ValueError when no strategies.
- `extract_metrics(stats)` -> `fitness.Metrics` with the EXACT mapping of INTERFACES.md §2:
  total_return_pct = profit_total*100; max_drawdown_pct = max_drawdown_account*100;
  sharpe/sortino/profit_factor/expectancy as-is; trades = total_trades;
  pair_coverage = traded_pairs/len(pairlist) (0.0 if empty); stability =
  positive_months_fraction(summary); complexity = 1.0.
- `positive_months_fraction(summary)` — months from `summary["periodic_breakdown"]["month"]`
  with profit_abs > 0 / total; missing/empty -> 0.0.
- `drop_top_n_trades(trades, n)` — sort by profit_abs desc, drop first n; return
  {"trades_after": int, "profit_abs_after": float, "profit_factor_after": float|None}
  (None when gross_loss == 0).
