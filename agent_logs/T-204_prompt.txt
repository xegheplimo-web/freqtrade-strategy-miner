  A) FEE: backtest (original strategy, tuned params auto-applied) with args =
     pipeline.backtest_args(...) + ["--fee", str(base_fee * fee_multiplier)]. Pass iff
     profit_total > 0 AND profit_factor >= 1.0. Record run (stage "robustness",
     notes="check=fee").
  B) PERTURB: for k in range(perturb_runs): seed = (candidate_id * 1000 + k); params =
     params.read_params_file(<generated>/<Class>.json) -> params.perturb_params(params,
     perturb_pct, rng=random.Random(seed)); copy strategy text to
     `<user_data>/strategies/robustness/<Class>_p{k}.py`; sidecar via
     params.write_params_file(that path, perturbed, strategy_name=<Class>); backtest with
     `--strategy-path` = robustness dir (container `/freqtrade/user_data/strategies/robustness`)
     — build args by copying pipeline.backtest_args shape but overriding strategy-path
     (write a local helper `_robustness_backtest_args(ctx, class_name, timerange, py_dir)`).
     Per-run pass iff profit_total > 0 AND profit_factor >= 0.8. Check passes iff
     >= 2/3 of runs pass (use actual run count: passed >= ceil(0.66 * perturb_runs)).
     Record each run (notes=f"check=perturb k={k} seed={seed}").
  C) DROP-TOP: load the LATEST validation-run artifact from the store
     (runs_for(candidate_id, "validation") last artifact_path); parse trades via
     results.load_backtest_json -> strategy stats -> trades list; n = max(5,
     ceil(drop_top_frac * len(trades))); result = results.drop_top_n_trades(trades, n).
     Pass iff profit_abs_after > 0 AND (profit_factor_after is None OR
     profit_factor_after >= 0.8 * profit_factor_before). No validation artifact ->
     check fails with note "no validation artifact".
  - Overall: ALL three checks pass -> "passed", else "rejected: <failed check names>".
  - set_stage_status("robustness", ...) once per candidate; return mapping.
