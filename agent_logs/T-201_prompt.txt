## REQUIREMENTS
### pipeline/__init__.py — foundation (frozen additions; INTERFACES.md §7 shapes them)
- `PipelineContext` frozen dataclass EXACTLY as INTERFACES.md §7 (root, miner_cfg, runner,
  store, user_data, generated_dir, results_dir, ft_config_container, generated_dir_container,
  results_dir_container).
- `make_context(root, *, config_path=None, runner=None, db_path=None) -> PipelineContext`:
  loads config (default `<root>/config/miner.json`), builds user_data paths
  (`<root>/freqtrade/user_data/...`), defaults runner=DockerRunner(user_data),
  store=Store(db_path or `<root>/output/miner.db`), ensures generated/results dirs exist,
  sets the three container-path strings (`/freqtrade/user_data/...`).
- `sync_ft_config(ctx) -> Path`: writes `<root>/freqtrade/user_data/config.miner.json` by
  merging `freqtrade/config.example.json` with miner config values (pairs -> pair_whitelist,
  exchange.name, trading_mode, margin_mode "isolated" for futures, stake_currency USDT,
  timeframe). Returns the path. (File is gitignored; content must be valid JSON.)
- `backtest_args(ctx, class_name, timerange, *, export="trades") -> list[str]`:
  EXACT list: ["backtesting", "--config", ctx.ft_config_container, "--strategy", class_name,
  "--strategy-path", ctx.generated_dir_container, "--timerange", timerange,
  "--export", export]. (All container paths.)
- `find_latest_artifact(ctx, since_ts: float) -> Path | None`: look in ctx.results_dir:
  prefer `.last_result.json` ({"latest_backtest": "<zip name>"}) when its zip mtime >=
  since_ts; else the newest `backtest-result-*.zip` with mtime >= since_ts; else newest
  overall (best effort); None if no zip at all. Never return `*_config.json`.
- `record_stage_run(ctx, candidate_id, stage, args, result, *, artifact_path=None,
  metrics=None, notes=None) -> int`: thin wrapper over Store.record_run using the RunResult
  (argv=result.argv, exit_code, duration_s) — so stages never hand-roll store calls.
### pipeline/fast_gate.py — stage 3 (WORKFLOW.md) 
- `FastGateResult` dataclass: `generated: int`, `backtested: int`, `failed_runs: int`,
  `rejected: int`, `shortlisted: tuple[int, ...]` (candidate ids), `scores: dict[int, float]`
  (candidate id -> fitness score for survivors), `artifact_paths: dict[int, str]`.
- `run_fast_gate(ctx, *, count=None) -> FastGateResult`:
  1. Generate `count or cfg["candidate_count"]` genomes via GenomeGenerator (cfg seed /
     timeframe / can_short), write each strategy with compiler.write_strategy into
     ctx.generated_dir, upsert each into ctx.store (py_path = host path relative to root or
     absolute — pick one and be consistent; document it).
  2. For each candidate: `sync_ft_config` NOT needed per candidate; run backtest with
     ctx.runner.run(backtest_args(...train_timerange...), log_dir=<worktree
     agent_logs>, log_name=f"fast_gate_{class_name}.log")`; on exit_code != 0 ->
     record_stage_run + store.set_stage_status("fast_gate", "failed") + count failed; continue.
  3. On success: find artifact (find_latest_artifact), parse via
     results.parse_backtest_result, extract_metrics, record_stage_run with metrics dict
     (dataclasses.asdict of Metrics), set status "passed"/"rejected" via
     fitness.passes_hard_filters(**cfg["hard_filters"]).
  4. Shortlist: rank survivors by fitness.score desc; k = max(int(ceil(top_fraction *
     generated)), min_candidates); take top k (if fewer survivors, take all survivors);
     set_stage_status("fast_gate", "shortlisted") for chosen, "rejected" for other survivors.
  5. Return FastGateResult (scores = survivor scores for ALL survivors, not only shortlisted;
     shortlisted = chosen ids).
